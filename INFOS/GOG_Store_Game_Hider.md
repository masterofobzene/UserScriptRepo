### USE CASE:
--------------
Block tag-abused games from appearing.

### USAGE:
---------------
On each game card a transparent black "X" button appears so you can hide it if you want effectively taking care of 
shitty games that use tags you like. It has persistent storage so you do this
one time per game. If you like to unblock a game, search for it in the "Values" tab of the script and delete the entry.

1.2: New code refactor. Added a button to load all the pages into one long page to avoid empty page numbers in the normal
    pagination after filtering. It also now loads the screenshots of the games above each gamecard since the original code 
    was not being triggered when listing the games. We also add the search on pir*te sites buttons on each card as well as
    the gameplay video button too because the gamecards where big enough with a lot of empty space in them.


### WHY?:
---------------
Tag abuse is a widespread normal bad practice nowadays. If you think, you will realize 70% of the games have for example
"simulation" tag, one would think these are aircraft sims, or racing sims, or military sims, but no, you can get
"Walking simulator" or "Grass Simulator" or "Goat Simulator". It is also present on "normal" games like "Colony builders"
too, making this a complete mess. Everything is considered a simulation nowadays but this is not aimed at that tag only,
it helps with all the content available. Tag abuse made the search system useless basically. Removing Simulator tag will 
remove 70% of the store. This is where this script comes to aid the abused user, letting him/her remove trash surgically
without removing games they may want to see.
