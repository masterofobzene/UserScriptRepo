### USE CASE:
--------------
Qwen Quality Of Life (QoL) script. 

- Fixes selection inside code blocks
- Forces no text wrapping in code blocks.
- Can add predefined prompts like "give easy copy paste instructions", "be concise", "never use chinese", etc 

### USAGE:
---------------
After installation you will see the small circular button on the top right, choose which prompts will be automatically
added to your prompt everytime.


### WHY?:
---------------
Deepseek started putting harsh limits to their service so we now have to rely on many limited services for coding. 
That means many different services with their quirks. Qwen is one of those alternatives.
