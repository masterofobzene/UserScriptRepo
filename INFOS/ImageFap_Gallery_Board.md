### USE CASE:
--------------
Gives a simpler and easier UI by loading and showing all thumbnails like a booru style page so you don't have to
pick a gallery, see if the images are what you like, closing and opening another. This simply paginates all into one
infinite scroll page. It replaces the "User gallery hider" userscript, so you can hide trash and block users. 
You can even manually *import the blacklist from "User gallery hider"* so you keep your blacklist after migrating.

### USAGE:
---------------
Click on the "⚡ Booru Mode" button.

⚠ If you find that clicking an image/gif shows a different one, **its a site-side known issue!**


1.2:  Major overhaul, save the last page loaded (save sessions), load them, stop load/resume, fixed duplicate galleries loaded.

1.3: Added a "copy gallery link" button for each gallery for downloading using gallery-dl or any other downloader.

1.4: fixed a major bug that only loaded the first page of each gallery instead of the full gallery.

### WHY?:
---------------
With so many random content galleries, you don't know exactly whats inside by just looking at the first 4 preview
images that the site shows. This userscript presents all galleries contents (except the ones manually blacklisted) in a "booru"
style page, so you don't have to open each gallery nor miss content.
